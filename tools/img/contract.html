Gesso · the contract

Every operation says what it does. A refusal names itself.

Readonly looks

Needs nothing. Lists, finds, measures. A reading is a copy; it never changes afterwards.

Net::sockets().listening().ofPid(4120)
// tcp 0.0.0.0:443 listening (pid 4120)
Net::routeTo(Addr::parse("8.8.8.8"))
// default via 192.168.1.1 dev Ethernet metric 100
Changeyour own things

What an ordinary user may do to their own process or files. The system still has the last word.

Procs::setPriority(pid, Priority::Idle)
Fs::setReadOnly(path, true)
Fs::canMakeLink().explain()
// cannot tell without trying: the folder's permissions decide
Adminthe machine

Needs an elevated session. Asked beforehand, answered with the privilege and the reason.

Procs::canSetPriority(Priority::Realtime).explain()
// needs an elevated administrator: real time can starve the system's own work
Procs::planSetPriority(21, Priority::Realtime)
// 1. [admin] set the priority of process 21 to real time
// (undo: set it back to high)

…and when the system says no

proc.setPriority: denied on process 4120 to real time: needs an elevated administrator
proc.imagePath: process 4120 no longer exists
net.routeTo: no route to 2001:db8::1
proc.signal: interrupt is not available on windows

Eight reasons, never false

Denied · Unsupported · Gone · Absent · Busy · Invalid · Expired · OsFailure — all a SysError, which is an IOException: a caller that already declares one carries them onward. An operating system's number never reaches a caller bare.
